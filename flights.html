Turn on live prices

Live fares come from Google Flights through SerpApi. A GitHub Action checks them once a day and saves them to this site.
  1. Sign up for a free account at serpapi.com (250 searches/month free; this uses about 120).
  2. Copy your API key from the SerpApi dashboard.
  3. In the GitHub repo: Settings → Secrets and variables → Actions → New repository secret. Name it SERPAPI_KEY and paste the key.
  4. Go to Actions → Update flight prices → Run workflow. Prices appear here a minute or two later, then refresh every morning.
