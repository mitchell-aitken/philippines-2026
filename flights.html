Turn on live prices

Live fares come from Google Flights through SerpApi. A GitHub Action checks them every morning.
  1. Get a free key at serpapi.com.
  2. Repo Settings → Secrets and variables → Actions → New repository secret, named SERPAPI_KEY.
  3. Actions → Update flight prices → Run workflow.
Flight prices are live from Google Flights and change daily. Ferry times and fares come from operator timetables; confirm before booking. All prices are per person.
